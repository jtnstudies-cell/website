# Dr. Jithin Paralthodi Abdulhudha — Personal Website

A responsive, static personal portfolio website with a midnight-black background and brilliant-orange accents. It uses plain HTML, CSS and JavaScript; no build step or package installation is required.

## Preview locally

1. Unzip the project (if downloaded as a ZIP).
2. Open `index.html` in a modern browser. Keep the `assets` folder beside it so the portrait and favicon load.

## Publish with Vercel

### Fastest: Vercel dashboard
1. Sign in to Vercel and choose **Add New → Project**.
2. Import the GitHub repository containing this folder, or use Vercel's static deployment workflow.
3. Set the project root to this folder (`dr-jithin-website` if the repository contains the parent folder).
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
5. Deploy. Vercel will provide a public `vercel.app` address.

### GitHub workflow
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the enclosing ZIP).
3. Import that repository in Vercel and deploy using the settings above.

## Before public launch

- In `index.html`, replace `hello@example.com` in the contact button with the professional email address you want visitors to use.
- Review the biography, experience timeline and project descriptions for accuracy and current status.
- Add any professional social/profile links you want displayed.
- Connect a custom domain in Vercel after deployment, if you own one.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation, reveal animations and current year
- `assets/dr-jithin-portrait.jpg` — supplied portrait
- `assets/favicon.svg` — site icon

No analytics, cookies, database or third-party form service is included.
